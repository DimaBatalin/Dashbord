# Пульт дня

Личный дашборд на один экран: дедлайны по учёбе, привычки и регулярные платежи.
Работает в браузере и устанавливается на телефон как приложение (PWA).

**Демо:** https://dimabatalin.github.io/Dashbord/

## Возможности

- Часы и прогресс дня / недели
- Свои блоки: создавайте, переименовывайте, меняйте порядок и ширину
- Светлая и тёмная тема
- Экспорт и импорт данных в JSON
- Синхронизация между устройствами через вход Google (Firebase) — у каждого пользователя свой набор блоков
- Работает офлайн

## Блоки

| Тип | Для чего |
|---|---|
| Дедлайны | задачи со сроком, подсветка срочных и просроченных |
| Привычки | отметка за день, последние 7 дней, серия |
| Платежи | сумма к оплате, отсчёт до ближайшего списания |
| Список | простой список: фильмы, книги, идеи |
| Чек-лист | пункты с галочкой |
| Заметка | свободный текст |

Новому пользователю создаются блоки «Дедлайны», «Привычки», «Финансы и подписки» и «Посмотреть».
Кнопка «Настроить» включает режим редактирования: перетаскивание за ⠿ или стрелки ↑ ↓,
ширина ½ / ↔, переименование по клику на заголовок, удаление ✕ и карточка «Новый блок» внизу.

## Установка на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте сайт → «Поделиться» → «На экран „Домой“».

## Структура

```
index.html             разметка
styles.css             стили
app.js                 логика и хранение данных
sw.js                  service worker (офлайн)
manifest.webmanifest   манифест PWA
icons/                 иконки приложения
firestore.rules        правила доступа к базе
```

Сборка не нужна — это статический сайт.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Service worker работает только по `http://localhost` или `https://`.

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
После изменений файлов увеличьте версию `CACHE` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.

## Синхронизация (Firebase)

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/), добавьте веб-приложение.
2. Authentication → Sign-in method → включите **Google**; в Authorized domains добавьте `dimabatalin.github.io`.
3. Firestore Database → создайте базу → Rules → вставьте содержимое `firestore.rules` → Publish.
4. Скопируйте конфиг в `FIREBASE_CONFIG` в `app.js`. Чтобы работать без облака, укажите `null`.
5. Рекомендуется: Google Cloud Console → APIs & Services → Credentials → ограничьте API-ключ по HTTP-referrer (`https://dimabatalin.github.io/*`, `http://localhost:*`).

Данные каждого пользователя хранятся в документе `users/{uid}`: поле `layout` — список блоков, поля `b_<id>` — записи блоков. Правила разрешают доступ только владельцу.
Без входа данные лежат в `localStorage` браузера; при первом входе они переносятся в аккаунт.
